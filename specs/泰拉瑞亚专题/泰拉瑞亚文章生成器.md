# 泰拉瑞亚专题文章生成器

> **用途**：读取 `terraria_scrape.md` 生成的状态文件，将图片上传到微信 CDN，生成完整 HTML 文章，并创建微信草稿。

## 使用方式

```bash
python3 terraria_article.py  # 实际脚本在 tools/game-discount-agent/ 项目目录下，本文档为知识库参考副本  # 确保先运行 terraria_scrape.md 生成状态文件
```

## 依赖

- `httpx`（HTTP 请求）
- `Pillow`（图片裁剪）
- `wechat_publisher.py`（微信 API 封装：`get_access_token`、`ensure_thumb`、`create_draft`、`Article`）

## 输入

- `terraria_state.json`（由 `terraria_scrape.md` 生成的状态文件）
- Steam header 图（通过 CDN URL 下载）

## 输出

- 完整 HTML 文章文件（`terraria_article.html`）
- 微信草稿（通过 `create_draft` API）
- 更新后的状态 JSON（含 media_id）

## 工作流程

1. 从状态文件读取 CDN URL
2. 上传 header 图到微信 CDN
3. 上传截图到微信 CDN
4. 生成 300x200 缩略图并上传
5. 构建完整 HTML 文章（含封面、引用、游戏介绍、截图画廊、信息卡片）
6. 调用微信草稿 API 创建图文消息

> 另有 **HTML-only 版本**（`terraria_html.py`）仅生成 HTML，不上传不发布，适用于只需要重新生成 HTML 的场景。
