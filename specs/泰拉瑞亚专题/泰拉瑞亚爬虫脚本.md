# 泰拉瑞亚专题爬虫脚本

> **用途**：从 Steam 抓取泰拉瑞亚的 header 图和截图，上传到微信 CDN，并生成状态文件供后续 HTML 生成和草稿创建使用。

## 使用方式

```bash
python3 terraria_scrape.py [APPID] [IMAGES_DIR] [STATE_FILE]
```

- `APPID`：Steam AppID（泰拉瑞亚为 `105600`）
- `IMAGES_DIR`：图片存储目录（可选）
- `STATE_FILE`：状态文件输出路径（JSON）

## 依赖

- `httpx`（HTTP 请求）
- `Pillow`（图片裁剪/缩放）
- `wechat_publisher.py`（微信 API 封装，同目录下）

## 输出

- 微信 CDN 上的 header 图 URL
- 微信 CDN 上的截图 URL 列表
- 微信缩略图 media_id（300x200 center-crop）
- 状态 JSON 文件（供 `terraria_article.md` 使用）

## 工作流程

1. 调用 Steam API 获取游戏截图列表
2. 下载 header 图 + 前 6 张截图
3. 上传到微信永久素材库，获取 CDN URL
4. 裁剪 header 图为 300x200 缩略图并上传
5. 保存所有状态到 JSON 文件
