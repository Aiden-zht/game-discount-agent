## 2. 数据采集

### 2.1 采集时间点

| 时间 | 采集内容 | 原因 |
|------|----------|------|
| 发布后 1 小时 | 阅读量 | 判断标题吸引力 |
| 发布后 24 小时 | 阅读量、分享量、收藏量 | 完整数据窗口 |
| 发布后 48 小时 | 最终数据、留言关键词 | 长尾效果 |

### 2.2 采集 API

```python
def get_article_stats(token, article_id):
    """获取文章数据（发布后 24 小时调用）"""
    url = "https://api.weixin.qq.com/datacube/getarticlesummary"
    params = {"access_token": token}
    data = {
        "begin_date": publish_date,
```

### 2.3 采集字段

| 字段 | 说明 | 用途 |
|------|------|------|
| `read_count` | 阅读人数 | 标题吸引力 |
| `share_count` | 分享人数 | 内容传播力 |
| `favorite_count` | 收藏人数 | 内容价值 |
| `like_count` | 点赞人数 | 用户认可度 |
| `comment_count` | 留言数 | 互动参与度 |
| `read_from_share` | 从分享来的阅读 | 传播链效果 |
| `read_from_search` | 从搜一搜来的阅读 | SEO 效果 |
