## 4. 数据驱动 Agent 行为

### 4.1 数据反馈如何影响内容

数据反馈的目的是帮助 Agent 了解历史表现，优化后续内容方向。反馈在每次写作任务启动时注入创作者 Agent 的 Prompt 中。

反馈内容应包含：

| 反馈维度 | 数据来源 | 对内容的影响 |
|----------|----------|-------------|
| 平均阅读量 | 文章统计数据 | 调整标题策略和选题方向 |
| 最佳文章类型 | 按类型聚合数据 | 优先选择高表现类型 |
| 最佳标签 | 按标签聚合数据 | 选题时倾向高互动标签 |
| 近期趋势 | 最近 N 篇数据 | 上升期延续策略，下降期调整方向 |

### 4.2 注入时机

数据反馈由定时任务触发采集后写入 KPI，在每次创作任务开始时由 Agent 自行读取并注入：

```
定时采集任务（每天凌晨 1:00）
     ↓
写入 KPI 存储
     ↓
下次创作任务启动时 → 读取 KPI → 构造反馈 Prompt → 注入创作者
```

定时任务规范见 [[业务/写作/通用/08-定时任务通用规范]]。

### 4.3 数据看板

Agent 可本地维护数据看板用于快速参考。看板由定时采集任务自动更新，不入知识库。

看板内容示例：

| 维度 | 展示内容 |
|------|----------|
| 整体指标 | 总阅读、总分享、平均阅读、趋势变化 |
| 文章排名 | 按阅读量降序排列近期文章 |
| 类型分析 | 各内容类型的平均表现 |
| 标签分析 | 各标签的平均阅读量 |

数据看板的具体格式和更新方式由 Agent 自行决定。
