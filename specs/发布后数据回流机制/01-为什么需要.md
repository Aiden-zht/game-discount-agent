## 1. 为什么需要

```
当前流程（无反馈）：
生成 → 审查 → 发布 → 结束（数据丢失）

改进后（有反馈）：
生成 → 审查 → 发布 → 24h后采集数据 → 写入KPI → 影响下次生成
```

没有反馈 = 盲人摸象。Agent 不知道推荐什么游戏读者更买账。

数据反馈让 Agent 看到真实效果：

- **标题策略优化**：知道哪些关键词能提高打开率
- **选题方向调整**：了解读者偏爱折扣汇总还是单品推荐
- **发布时间优化**：对比不同时段的阅读数据
- **内容结构改进**：分析高互动文章的段落排版和配图策略

数据采集由定时任务触发（详见 [[业务/写作/通用/08-定时任务通用规范]] 和 [[业务/写作/公众号/创作规范/发布后数据回流机制/05-定时采集任务]]），写入 KPI 后在下次创作时自动注入 Prompt。
