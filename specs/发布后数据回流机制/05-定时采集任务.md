# 5. 定时采集任务

## 5.1 概述

数据采集需要定时自动执行，由定时任务系统负责触发。通用规范见 [[业务/写作/通用/08-定时任务通用规范]]。

## 5.2 采集任务定义

```yaml
name: 公众号文章数据采集
schedule: "0 1 * * *"
timezone: Asia/Shanghai
action: |
  1. 获取前日发布文章列表
  2. 调用数据采集 API 获取阅读/分享/收藏等数据
  3. 写入 KPI 存储
retry:
  max_attempts: 3
  interval: "递增（5min → 15min → 30min）"
on_failure: 跳过本轮采集，等待下个周期
log: 记录每次采集的开始时间、采集篇数、成功/失败状态
```

## 5.3 采集范围

- 采集发布满 24 小时的文章（数据趋于稳定）
- 每次采集前日所有发布文章
- 同一篇文章最多采集 3 次（发布后 24h、48h、7d），取最终数据

## 5.4 注意事项

- 公众号 API 有调用频率限制（具体限制见 [[业务/写作/公众号/创作规范/02-发布API手册]]）
- 采集任务失败不影响当天主要内容生成流程
- 采集结果直接写入 KPI，无需人工确认
