# 每日微信公众号文章自动生成流程

## 概述

本流程定义了一整套"每日定时生成并发布公众号文章"的生命周期。所有定时调度遵循 [[业务/写作/通用/08-定时任务通用规范]]，各阶段细节由对应的规范文件定义。

## 全生命周期

```
定时触发器（每天早上 10:00）
     ↓
① 数据采集 ─── 从 Steam / Epic 拉取折扣数据
     ↓
② 内容生成 ─── 创作者 Agent 撰写文章
     ↓
③ 质量审查 ─── 审查者 Agent 检查 + 修复循环
     ↓
④ 发布 ───── 调用公众号 API 创建草稿并发布
     ↓
⑤ 数据回流 ─── 24h 后采集阅读/分享数据 → 更新 KPI
     ↓
⑥ 反馈注入 ─── KPI 数据影响下次生成时的 Prompt
```

## 任务定义

```yaml
name: 每日公众号文章生成
schedule: "0 10 * * *"
timezone: Asia/Shanghai
action: 数据采集 → 文章生成 → 质量审查 → 发布 → 记录结果
retry:
  max_attempts: 3
  interval: "递增（5min → 15min → 30min）"
on_failure: |
  跳过当日发布，记录失败原因。
  连续失败 3 天触发告警。
log: |
  记录每步耗时、结果、异常。
  由 Agent 本地维护，不入知识库。
```

## 异步数据采集任务

```yaml
name: 公众号数据采集
schedule: "0 1 * * *"
timezone: Asia/Shanghai
action: 采集前日发布文章数据 → 写入 KPI
retry:
  max_attempts: 3
on_failure: 跳过本轮，下个周期重试
```
