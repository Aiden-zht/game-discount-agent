## 3. 封号风险规避

### 3.1 高风险行为清单

```markdown
❌ 绝对不能做：
├── 发布政治敏感内容
├── 传播虚假信息/谣言
├── 发布低俗/色情/暴力内容
├── 诱导分享/关注（明文禁止）
├── 抄袭他人原创内容
├── 使用外挂/刷量工具
└── 未经授权使用他人商标/版权内容

⚠️ 谨慎操作：
├── 追热点时注意信息真实性
├── 使用图片注意版权
├── 推广合作注意合规
├── 新账号初期避免大量发布
└── 避免短时间内大量推送
```

### 3.2 安全发布检查清单

> **自动化版本**：以下 8 项检查已落地为 Agent B 的 23 项自动审查规则（含 B6/B21-B23 图片专项检查）。
> 完整定义见 [[业务/写作/公众号/创作规范/01-平台特有流程]] 第 3 节。

每篇文章发布前检查：

- [ ] 标题与内容一致，非标题党
- [ ] 内容真实准确，无虚假信息
- [ ] 图片有合法使用权
- [ ] 无诱导分享/关注话术
- [ ] 无抄袭（原创或已获授权）
- [ ] 链接安全可访问
- [ ] 敏感词检查通过
- [ ] 符合账号定位和领域

### 3.3 敏感词规避

**常见敏感词类型**：

| 类型 | 示例（避免使用） | 替代方案 |
|------|------------------|----------|
| 绝对化用语 | 最好、第一、唯一 | 优质、领先、知名 |
| 虚假承诺 | 保证赚钱、100% 有效 | 预期收益、参考效果 |
| 低俗用语 | 各类脏话、暗示性语言 | 正常表达 |
| 政治相关 | 领导人姓名、政治事件 | 不涉及 |
| 医疗相关 | 治疗、治愈、药效 | 保健、辅助 |
