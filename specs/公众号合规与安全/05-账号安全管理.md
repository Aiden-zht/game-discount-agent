## 5. 账号安全管理

### 5.1 安全设置

- [ ] 绑定运营者微信号（开启登录保护）
- [ ] 设置安全邮箱（非公共邮箱）
- [ ] 开启操作保护（重要操作需验证）
- [ ] 定期更换密码
- [ ] 不在公共设备上保存登录状态
- [ ] 管理员微信号绑定银行卡（实名验证）

### 5.2 防盗措施

| 措施 | 说明 |
|------|------|
| **登录保护** | 新设备登录需手机验证 |
| **操作保护** | 修改密码、API 配置等需验证 |
| **IP 白名单** | 限制 API 调用来源 |
| **定期审计** | 检查登录记录、操作日志 |
| **备份数据** | 定期导出文章和用户数据 |

### 5.3 被盗应急

1. 立即通过安全助手冻结账号
2. 联系微信客服申诉
3. 修改所有相关密码
4. 检查 API 配置是否被篡改
5. 检查文章是否被恶意修改/删除
6. 通知粉丝账号异常（如被发布恶意内容）
