## 1. 平台审核机制

### 1.1 内容审核流程

```
发布内容 → 系统初审 → 人工复审（可选）→ 发布/驳回
              │
              ├── 机器审核：关键词匹配 + 图片识别 + 语义分析
              └── 人工审核：敏感内容、被举报内容
```

### 1.2 审核时间

| 情况 | 审核时间 |
|------|----------|
| 正常文章 | 即时发布（系统自动审核） |
| 被举报文章 | 1-24 小时 |
| 敏感内容 | 可能被延迟或人工审核 |
| 新账号初期 | 审核可能更严格 |

### 1.3 审核结果

| 结果 | 说明 | 处理方式 |
|------|------|----------|
| **通过** | 正常发布 | 无需操作 |
| **驳回** | 违反平台规则 | 修改后重新发布 |
| **删除** | 严重违规 | 文章被删除，可能处罚账号 |
| **封号** | 多次严重违规 | 账号被永久封禁 |
