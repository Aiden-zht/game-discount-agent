# 微信公众号文章约束模板（游戏/推荐类）

## 1. 排版规范

| 项目 | 值 |
|------|------|
| 正文字体大小 | 15px（正文）/ 16px（段落首段） |
| 正文颜色 | #333333 / #555555（引用）/ #2c3e50（标题） |
| 行间距 | 1.8倍 |
| 段间距 | 20px |
| 对齐方式 | 左对齐 |

## 2. 标题规范

```html
<h2 style="color: #e74c3c; border-left: 4px solid #e74c3c; padding-left: 12px; margin: 32px 0 16px 0; font-size: 20px;">🔥 板块名</h2>
```

板块副标题：14px, #888888, margin: 0 0 16px 0

## 3. 游戏卡片规范

```html
<div style="background:#f9f9f9;border-radius:8px;padding:16px;margin:16px 0">
  <p style="font-size:16px;font-weight:bold;color:#2c3e50;margin:0 0 6px 0">游戏名称</p>
  <p style="font-size:14px;color:#666666;margin:0 0 8px 0">游戏简介文字...</p>
  <p style="font-size:12px;margin:0">
    <span style="color:#888888;text-decoration:line-through">¥198</span>
    <span style="color:#e74c3c;font-weight:bold"> ¥29.7 (-85%)</span>
    <span style="color:#27ae60;margin-left:8px">好评 95%</span>
  </p>
</div>
```

好评率颜色：≥90% #27ae60, ≥80% #27ae60, ≥70% #e67e22, ≥50% #e67e22, <50% #e74c3c, 免费 #888888

## 4. 引用块（金句/总结）

```html
<blockquote style="border-left:4px solid #4a90d9;padding:12px 16px;margin:16px 0;background:#f0f7ff;border-radius:0 8px 8px 0;font-style:italic;color:#555;line-height:1.8">
  引用文字内容...
</blockquote>
```

## 6. 常用布局

场景对比：`<div style="background:#f8f9fa;border-radius:10px;padding:14px;margin:12px 0;border-left:4px solid #3498db">`

信息卡片渐变：`background:linear-gradient(135deg,#4a90d9,#667eea);`

分割线：`<hr style="border:1px solid #eee;margin:30px 0 20px 0">`

文末引导：12px, #aaaaaa, 居中

## 7. Markdown 转换与列表安全渲染规则

### 7.0 转换架构

公众号发布链路必须拆成三层，禁止把规则散落到文章正文或手工修改 HTML：

```text
Markdown 正文 → 标准 Markdown 引擎 → 标准 HTML → WeChat HTML adapter → 草稿发布
```

执行要求：

- Markdown 解析必须交给成熟标准引擎（如 Python `markdown`、`markdown-it`），不得自写 Markdown 解析器。
- WeChat HTML adapter 只负责微信公众号兼容性：inline CSS、伪列表段落、图片 CDN、禁用标签清理、标题/封面/API 约束。
- Markdown 列表必须在 adapter 中转换成带 `•` / `1.` 前缀的段落，不得在最终 HTML 中保留 `<ul>/<ol>/<li>`；不得要求作者在 Markdown 中手写 style，也不得依赖发布前手改 HTML。
- 发布前验证对象是最终 HTML，不是 Markdown 原文。

微信公众号文章最终必须以 HTML 为准，不得依赖 Markdown 列表自动转换。尤其禁止在列表项之间插入空行，因为微信编辑器可能把空段落渲染成异常无序列表或额外圆点。

### 7.1 禁止写法

```markdown
- 第一条

- 第二条

- 第三条
```

禁止原因：列表项之间的空行会被部分编辑器识别为多个独立列表，或把空行渲染成空 `<li>`。

### 7.2 推荐 HTML 写法

```html
<p style="font-size:15px;color:#333;line-height:1.75;margin:0 0 4px 0">• 第一条</p>
<p style="font-size:15px;color:#333;line-height:1.75;margin:0 0 4px 0">• 第二条</p>
<p style="font-size:15px;color:#333;line-height:1.75;margin:0 0 4px 0">• 第三条</p>
```

### 7.3 列表生成规则

- 若输出 HTML，必须把 Markdown `- `、`* `、`1. ` 列表语法转换成伪列表段落，不得保留 Markdown 原符号。
- 最终 HTML 不得出现 `<ul>`、`<ol>`、`<li>`，避免微信编辑器二次渲染成异常圆点。
- 列表项之间用段落 `margin-bottom` 控制间距，不用空行控制间距。
- 列表前后可用段落或卡片分隔，但列表内部不能插入空段落。
- 文章发布前必须检查 HTML 中是否存在 `<ul>`、`<ol>`、`<li>`、Markdown 残留列表符号。

## 8. 简版折扣表格（无图紧凑版）

> 用于文章末尾的"更多好价"板块，纯文字表格，无配图。
> 结构定义见 [[业务/写作/公众号/创作规范/游戏折扣文章风格库/02-内容结构模板#2.4-简版折扣列表无图紧凑版]]

```html
<div style="margin:24px 0">
  <h2 style="color:#e74c3c;border-left:4px solid #e74c3c;padding-left:12px;font-size:18px;margin:0 0 12px 0">📋 更多好价</h2>
  <blockquote style="border-left:4px solid #4a90d9;padding:8px 12px;margin:0 0 16px 0;background:#f0f7ff;border-radius:0 6px 6px 0;font-size:13px;color:#555">
    以下游戏也有不错折扣，篇幅有限不一一细说，有兴趣的可以康康 👀
  </blockquote>
  <table style="width:100%;border-collapse:collapse;font-size:13px">
    <tr style="background:#f5f5f5">
      <th style="padding:8px 6px;text-align:left;color:#888">游戏名</th>
      <th style="padding:8px 6px;text-align:center;color:#888">原价</th>
      <th style="padding:8px 6px;text-align:center;color:#e74c3c">现价</th>
      <th style="padding:8px 6px;text-align:center;color:#888">折扣</th>
      <th style="padding:8px 6px;text-align:center;color:#888">好评</th>
    </tr>
    <tr style="border-bottom:1px solid #eee">
      <td style="padding:8px 6px;font-weight:bold;color:#333">游戏A</td>
      <td style="padding:8px 6px;text-align:center;color:#888;text-decoration:line-through">¥198</td>
      <td style="padding:8px 6px;text-align:center;color:#e74c3c;font-weight:bold">¥29.7</td>
      <td style="padding:8px 6px;text-align:center"><span style="background:#e74c3c;color:#fff;padding:1px 4px;border-radius:3px;font-size:11px">-85%</span></td>
      <td style="padding:8px 6px;text-align:center;color:#27ae60">95%</td>
    </tr>
  </table>
</div>
```
