## 5. 操作方式

### 5.1 手动标记（当前阶段）

操作者可以通过对话告知 Agent 标记内容：

```
帮我标记一下今天发布的文章：
- 标题从"今日折扣"改成了"今日折扣精选 | 3款史低"
- 原因是加了数字和情绪词
- 质量评级：high
```

Agent 执行：

```python
state["human_review"] = {
    "reviewed": True,
    "reviewer": "大钱",
    "reviewed_at": "2026-06-10T15:30:00",
    "edits": [
        {"field": "title", "before": "今日折扣", "after": "今日折扣精选 | 3款史低", "reason": "加数字和情绪词提升点击率"}
    ],
    "quality_rating": "high",
    "notes": "手动标记"
}
```

### 5.2 批量标记

```
帮我批量标记最近 5 篇文章的人工编辑记录，我来告诉你每篇改了什么。
```
