## 2. 标记格式

### 2.1 在 state JSON 中标记

```json
{
    "title": "今日折扣精选 | 06-10",
    "status": "published",
    "human_review": {
        "reviewed": true,
        "reviewer": "大钱",
        "reviewed_at": "2026-06-10T15:30:00",
        "edits": [
            {
                "field": "title",
                "before": "今日游戏折扣推荐",
                "after": "今日折扣精选 | 3款史低神作",
                "reason": "标题加数字和情绪词，提升点击率"
            },
            {
                "field": "digest",
                "before": "推荐几款打折游戏",
                "after": "全面战争7.9元，还有2款史低神作",
                "reason": "摘要加具体游戏名和价格，增加吸引力"
            }
        ],
        "quality_rating": "high",
        "notes": "标题改动效果好，可作为 few-shot 示例"
    }
}
```

### 2.2 标记字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `reviewed` | bool | 是否经过人工审核 |
| `reviewer` | string | 审核人标识 |
| `reviewed_at` | datetime | 审核时间 |
| `edits` | array | 具体编辑记录 |
| `edits[].field` | string | 编辑的字段（title/digest/content） |
| `edits[].before` | string | 编辑前的内容 |
| `edits[].after` | string | 编辑后的结果 |
| `edits[].reason` | string | 编辑原因（学习样本的关键） |
| `quality_rating` | string | high/medium/low |
| `notes` | string | 补充说明 |
