## 3. 标记流程

```
文章发布
    │
    ▼
人工审核（可选）
    │
    ├── 无需修改 → human_review.reviewed = false
    │
    └── 需要修改 → 人工编辑
                    │
                    ▼
               记录 edits（before/after/reason）
                    │
                    ▼
               更新 state JSON
                    │
                    ▼
               高质量文章 → 存入 few-shot 示例库
```
