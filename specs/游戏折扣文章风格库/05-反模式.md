## 5. 反模式（必须避免）

### 5.1 内容反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|----------|
| 标题党 | 标题与内容不符 | 标题准确反映内容 |
| 堆砌信息 | 一屏 20 款游戏无重点 | 分层推荐，重点突出 |
| 无配图长文 | 纯文字超过 500 字 | 每 3-4 段配 1 张图 |
| 复制粘贴 | 直接搬运 Steam 描述 | 用自己的话重新写 |
| 无价格信息 | 只推荐不给价格 | 每款游戏必须有价格 |
| 无截止时间 | 限时折扣不标注 | 必须标注截止时间 |

### 5.2 排版反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|----------|
| 字太小 | <13px 阅读困难 | 正文 15px |
| 颜色太多 | >3 种颜色混乱 | 正文+强调+辅助 三色 |
| 段落太长 | >6 行/段 手机阅读累 | 拆分为 2-3 行/段 |
| 无分割线 | 内容混在一起 | 用 `<hr>` 分隔板块 |
| 封面模糊 | 像素过低 | 至少 900x383px |
| 无文末引导 | 缺少互动引导 | 加分享引导语 |
| 配图裂图/空图 | 图片 URL 不可访问或使用了未上传的占位 URL | 按 [[业务/写作/公众号/创作规范/09-图片治理规范]] 上传验证后再写入 HTML |
| 配图 URL 为 Steam 直链 | Steam CDN 在微信端不可访问，导致图片裂图 | 必须上传到微信 CDN 后再使用 |
| **图片与游戏不对应** | 游戏 A 的截图放到游戏 B 的卡片区块 | 每张图片标注 game_id，插入时严格按 game_id 就近放置 |
| **整篇文章只有有图推荐** | 所有游戏都做成大卡片，文章过长、信息密度低 | 重点游戏用卡片+图片，其余放入简版折扣表格（无图） |

### 5.3 违规反模式

| 反模式 | 后果 | 正确做法 |
|--------|------|----------|
| 诱导关注 | 封号风险 | 自然引导 |
| 虚假价格 | 用户投诉 | 标注真实价格 |
| 抄袭搬运 | 原创投诉 | 重写内容 |
| 绝对化用语 | 广告法违规 | 用「推荐」「优质」替代 |
