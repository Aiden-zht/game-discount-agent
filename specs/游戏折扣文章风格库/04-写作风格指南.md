## 4. 写作风格指南

### 4.1 语气定位

**朋友式推荐**，不是说明书。

```
✅ 「这款游戏真的太好玩了，和女朋友一玩就是十几个小时」
❌ 「该游戏是一款2D沙盒冒险游戏，支持多人联机」

✅ 「G胖又来掏空你的钱包了」
❌ 「Steam平台近期开展了促销活动」
```

### 4.2 口语化表达

| 书面表达 | 口语化替换 |
|----------|-----------|
| 性价比极高 | 物超所值 / 血赚 |
| 画面精美 | 画面绝了 / 颜值拉满 |
| 值得购买 | 冲就完事了 / 闭眼入 |
| 游戏性出色 | 玩到停不下来 / 上头 |
| 折扣力度大 | 骨架价 / 白菜价 / 跌破底价 |
| 历史最低 | 新史低 / 史低背刺 |
| 限时免费 | 白给 / 喜加一 |

### 4.3 常用网络用语

| 用语 | 含义 | 使用场景 |
|------|------|----------|
| 等等党 | 等待降价的玩家 | 折扣推荐 |
| 背刺 | 买完就降价/突然新史低 | 意外低价 |
| 喜加一 | 免费领取游戏 | 限免 |
| 电子阳痿 | 对游戏失去兴趣 | 推荐语境 |
| G胖 | Gabe Newell (Steam) | 调侃 |
| 白给 | 免费获得 | 限免 |
| 种草 | 推荐让人想买 | 推荐 |
| 拔草 | 放弃购买 | 避雷 |
| 肝 | 花大量时间玩 | 游戏体验 |

### 4.4 禁止使用

```
❌ 「综上所述」「首先其次再次」→ 书面语
❌ 「尊敬的读者」→ 太正式
❌ 「该游戏具有...」→ 说明书语气
❌ 「请大家转发点赞」→ 诱导分享
❌ 大段连续无配图的文字 → 阅读体验差
```
