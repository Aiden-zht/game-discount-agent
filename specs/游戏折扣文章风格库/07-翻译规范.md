# 游戏名翻译规范

## 1. 翻译流程（三级回退）

游戏名显示格式：**English / 简体中文**（仅当英文名 ≠ 中文名时显示双语）

### 第 1 层：Steam API 中文名（权威源）

调用 `l=schinese&cc=CN` 获取 Steam 官方中文名。

- **必须加 `cc=CN`**：不加时 Steam 可能返回美区 USD 价格或英文名，导致价格/名称区域错配。
- 若返回的中文名与英文名相同，视为"无中文名"，进入第 2 层。

### 第 2 层：FALLBACK 回退表

硬编码的已知游戏名映射。适用场景：Steam API 返回英文名但社区有公认中文名。

**触发条件**：英文名与中文名相同（`cn_f == en_f`）或中文名为空。

> 注意：只对有官方中文名的游戏使用 FALLBACK，缩写/品牌名（如 R.E.P.O.）不应强行添加。

### 第 3 层：翻译 API 兜底

前两层均无结果时，调用 iFlytek MAAS（model: `xopqwen36v35b`）批量翻译。

- 翻译结果必须含中文字符（`\u4e00-\u9fff`）才覆盖。
- 翻译失败或返回英文时，显示纯英文名。

## 2. 价格显示规范

所有游戏价格必须显示为 **CNY 元**（人民币）。

- **Steam API 查询必须带 `cc=CN`** 参数，确保返回 CNY 价格。
- 若 `l=schinese` 不带 `cc=CN`，可能返回 USD 或其他区域价格，导致价格单位错误。
- 价格格式：`¥198.00`（原价划线）+ `¥49.50`（现价高亮）。

## 5. 截止时间标注规范

- **强制规则**：文章必须标注具体优惠截止日期，不可只用"限时领取，过期不候"等模糊文案。
- **格式**：每个游戏卡片/列表项显示 `⏰ 截止：YYYY年MM月DD日`；文章头部不显示任何截止日期提示，不得写统一“优惠截止时间”。
- **数据来源**：Steam `featuredcategories` API 中每个 item 自身的 `discount_expiration` 字段（Unix timestamp）。不得取所有游戏的最早截止日期后注入给全部游戏。
- **时区**：转换为北京时间（UTC+8），格式 `%Y年%m月%d日`。
- **降级**：若单款游戏缺失 `discount_expiration`，该游戏可不显示具体日期。不得用其他游戏的日期冒充。
- **实现**：`steam_scraper.py` — `_format_deadline()` 和 `_api_item_to_deal()`；`content_generator.py` — `_game_card()` 与更多推荐列表渲染。
- **验证**：B16 检查项验证限时标注；deadline 非空时必须显示该游戏自己的具体日期，并确认不同 `discount_expiration` 不会被统一覆盖。

## 6. 折扣标签规范

- **禁止使用"史低"标签**：Steam API 只返回当前折扣，不包含历史最低价数据。在没有 SteamDB 等第三方数据源验证的情况下，将 75%+ 折扣标记为"史低"属于无依据断言（BLOCKING 级错误）。
- **正确做法**：使用客观描述性标签，按折扣区间分级：
  - 75%+：🔥 **特惠**（非"史低"）
  - 50-74%：⭐ **超值**
  - 25-49%：👍 **推荐**
  - 0-24%：💫 **一般**
- **文案约束**：不得使用"历史最低价"、"全史最低"等需要历史数据支撑的表述。可用"限时折扣"、"今日特惠"等客观描述当前活动的用语。
- **实现位置**：`content_generator.py` — `DISCOUNT_TIERS` 常量，标签从"史低"改为"特惠"。
