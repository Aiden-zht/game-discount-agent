## 6. Agent A 使用指南

Agent A 在生成游戏折扣文章时，必须：

### 6.1 标题选择

- 从「高打开率标题模式」中选择 1 个公式
- 标题长度 15-25 字
- 包含具体数字或价格信息
- 不使用反模式中的标题禁忌
- 单款游戏推荐必须使用完整游戏名作为草稿标题和正文主标题；不得用简称、章节名或截断名替代（如不得把 `女王的游戏：盛世天下 女帝篇` 写成 `女帝篇推荐`）

### 6.2 内容结构

- 选择对应的内容模板（每日推荐/单款推荐/限免）
- 重点游戏放前面，用卡片突出
- 每款游戏必须有：名称、价格、好评率、一句话推荐
- 限时游戏必须标注截止时间
| **推荐数量**：主卡区最多展示 9 款游戏（按折扣分档 + 热度排序）。超过 9 款时，多余游戏 + DLC 合并到文章末尾的"📋 更多推荐"纯文字列表，格式：`双语名 + 折后价 + 划线原价 + 折扣% + [DLC]` |
- **推荐标准**：折扣力度 ≥ 10% 且好评率 ≥ 40% 即可入选，低于此标准或无配图则排除 |
- **排序规则**：先按折扣分档（史低≥75% → 超值50-74% → 其他<50%），每档内按 `discount_percent × review_score` 排序，跨档合并后取前 `main_card_max`（默认9）款展示为卡片
- **溢出处理**：超过 9 款时，其余游戏 + 所有 DLC 进入"📋 更多推荐"纯文字列表（无配图），用于让感兴趣的用户自行搜索 |

### 6.3 排版执行

- 参考排版经验总结中的参数
- 使用价格展示规范的 HTML 模板
- 段落不超过 5 行
- 每 3-4 段配 1 张图
- 每张配图必须经微信 CDN 上传成功后再写入 HTML，**不可直接用 Steam CDN URL 或占位文本**
- 每款推荐游戏至少配 1 张游戏截图

### 6.5 图片治理（必读）

Agent A 必须完整阅读并遵守 [[业务/写作/公众号/创作规范/09-图片治理规范]]，重点执行：
- 图片获取流程（I1-I8 红线），**尤其是 I5-I7 图片-游戏绑定规则**
- 图片上传验证标准（2.2 节），每张图必须标注 `game_id` 和 `game_name`
- 降级策略（4.1 节），确保每张图都有兜底
- A9-A12 自检通过后，才可输出 state JSON

### 6.6 图片-游戏映射校验规则

Agent A 生成 HTML 时必须确保：

| # | 规则 | 检查方法 |
|---|------|---------|
| M1 | 每张截图必须绑定一个游戏中存在的游戏（game_id 在 state.games 列表中） | 遍历 images，检查 game_id 是否在 games[].appid 中 |
| M2 | 游戏 A 的截图只出现在游戏 A 的卡片区块 | 检查 HTML 中每个游戏 card 附近的 img 的 game_id |
| M3 | 封面图（header）的 game_id = `__cover__` | 封面图不归属于任何具体游戏 |
| M4 | 简版折扣列表中的游戏不产生任何图片 | 表格区禁止出现 `<img>` 标签 |

### 6.4 风格检查

- 语气：朋友式推荐，口语化
- 用词：使用口语化表达替换表
- 禁止：书面语、诱导分享、绝对化用语
