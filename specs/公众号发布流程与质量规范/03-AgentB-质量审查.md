# Agent B：质量审查

## 3.1 职责

Agent B **独立于 Agent A** 运行，使用全新上下文（通过 `delegate_task` 调用），对内容进行全面质量审查。

**关键原则**：
- Agent B 不能看到 Agent A 的对话历史
- Agent B 只接收 state JSON 作为输入
- Agent B 的审查结果独立、客观

## 3.2 调用方式

```bash
# 主控 Agent 调用校验者
delegate_task(
    goal="公众号内容质量审查：读取 state JSON，执行质量检查（B1-B29），输出审查报告",
    context="规则见：业务/写作/公众号/创作规范/01-平台特有流程.md 第 3.3-3.6 节\nAgent B 仓库目录：<agent 各自的知识库路径>\nstate.json 路径：<实际路径>",
    toolsets=["web", "terminal", "file"]
)
```

## 3.3 基础质量检查（6 项）

| # | 检查项 | 规则 | 严重级别 |
|---|--------|------|----------|
| B1 | **标题党检测** | 标题不含「震惊」「不看后悔」「99%的人不知道」等夸张词汇；标题与正文内容相关 | BLOCKING |
| B2 | **敏感词检测** | 正文不含政治敏感词、违法词汇、低俗用语（使用敏感词库匹配） | BLOCKING |
| B3 | **内容真实性** | 数据/价格有来源标注；不含明显虚假信息（如「免费领100元」） | BLOCKING |
| B4 | **字数合规** | 正文 300-50000 字（过短无价值，过长阅读率低） | WARNING |
| B5 | **原创度** | 正文不与已发布文章高度重复（相似度 < 70%） | WARNING |
| B6 | **图片数量** | 至少 1 张配图，不超过 20 张 | WARNING |

## 3.4 合规安全检查（8 项）

| # | 检查项 | 规则 | 严重级别 |
|---|--------|------|----------|
| B7 | **无诱导分享** | 不含「转发到朋友圈」「分享给好友」「不转不是中国人」等诱导话术 | BLOCKING |
| B8 | **无诱导关注** | 不含「关注后可见全文」「关注领福利」等强制关注话术 | BLOCKING |
| B9 | **无抄袭** | 正文不与第三方内容高度相似（相似度 < 60%）；引用已注明出处 | BLOCKING |
| B10 | **链接安全** | 所有外部链接可访问、非钓鱼/木马域名 | BLOCKING |
| B11 | **图片版权** | 配图来源合法（自有/免费素材/已授权）；游戏截图用于评论目的可豁免 | WARNING |
| B12 | **无绝对化用语** | 不含「最好」「第一」「唯一」「100%有效」等广告法禁用词汇 | WARNING |
| B13 | **无虚假承诺** | 不含「保证赚钱」「包教包会」「零风险」等虚假承诺 | BLOCKING |
| B14 | **账号定位一致** | 内容与公众号定位（游戏折扣/推荐）相关，不偏离领域 | INFO |

## 3.5 排版规范检查（额外附加检查）

Agent B 还需检查排版是否符合 [[业务/写作/公众号/创作规范/04-文章模板]]：

| 检查项 | 规则 | 严重级别 |
|--------|------|----------|
| 字体栈 | 使用指定 font-family | WARNING |
| 正文字号 | 15px（首段 16px） | WARNING |
| 标题层级 | h2 有左侧边框装饰 | WARNING |
| 卡片样式 | 背景色 #f9f9f9，圆角 8px | INFO |
| 引用块 | 背景色 #f0f7ff，左侧 4px 边框 | INFO |
| B29 | **列表渲染安全** | 最终 HTML 不得残留 Markdown 列表语法；`<ul>/<ol>` 内不得出现空 `<li>`、空 `<p>`、连续 `<br>` 或由空行生成的多余列表圆点 | BLOCKING |

## 3.6 游戏折扣文章质量检查（6 项）

> 基于 [[业务/写作/公众号/创作规范/游戏折扣文章风格库/index]] 中的优秀案例和反模式

| # | 检查项 | 规则 | 严重级别 |
|---|--------|------|----------|
| B15 | **价格信息完整** | 每款推荐游戏必须包含：原价、现价、折扣幅度 | BLOCKING |
| B16 | **截止时间标注** | 限时折扣/限免游戏必须标注截止时间 | BLOCKING |
| B17 | **段落长度** | 单段不超过 200 字（手机屏 5-6 行） | WARNING |
| B18 | **配图关联** | 配图与上下文内容相关（游戏截图/操作界面） | WARNING |
| B19 | **口语化表达** | 不含书面语（「综上所述」「首先其次」），使用朋友式推荐语气 | WARNING |
| B20 | **重点分层** | 文章有明确的重点推荐（前 2-3 款）和次要推荐区分 | INFO |

## 3.7 图片专项质量检查（2 项）

> 基于 [[业务/写作/公众号/创作规范/09-图片治理规范]]，对图片上传质量和内容分布做专项检查。

| # | 检查项 | 规则 | 严重级别 |
|---|--------|------|----------|
| B21 | **配图上传成功率** | `upload_status=FAILED` 的图片占比 < 50%；如果封面图（thumb_media_id）状态为 FAILED 则直接 BLOCKING | BLOCKING |
| B22 | **配图分布密度** | 正文每 400 字至少有 1 张配图（含封面），纯文字连续段落不超过 4 段 | WARNING |
| B23 | **图片-游戏映射准确性** | 每张非封面图（game_id != `__cover__`）必须：1) game_id 非空 2) HTML 中该游戏的卡片区域前后 200 字符内至少出现 1 张该 game_id 的图片 | BLOCKING |
| B28 | **配图主题匹配** | 非游戏主题文章不得使用游戏封面、Steam header、游戏截图；知识库治理/Agent 工作流/技术方法论类文章若有配图，必须是流程图、架构图、信息图、界面截图或抽象视觉 | BLOCKING |

## 3.8 检查结果分类

| 级别 | 含义 | 处理方式 |
|------|------|----------|
| **BLOCKING** | 严重问题，必须修复 | 阻断发布，进入修复循环 |
| **WARNING** | 需要关注，但不阻断 | 记录到审查报告，可选择修复 |
| **INFO** | 信息性记录 | 仅记录，无需修复 |

## 3.9 审查报告输出格式

Agent B 输出 JSON：

```json
{"overall": "PASS", "blocking_count": 0, "warning_count": 2, "info_count": 3, "items": [{"code": "B1", "status": "PASS", "detail": "..."}, ...], "summary": "一句话总结"}
```
