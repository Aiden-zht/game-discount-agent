# 异常处理

## 7.1 常见异常

| 异常 | 原因 | 处理方式 |
|------|------|----------|
| `access_token` 获取失败 | AppID/AppSecret 错误或 IP 未加白名单 | 检查环境变量和 IP 白名单 |
| `access_token` 过期 | token 有效期 2 小时 | 重新获取 token |
| 图片上传失败 | 图片格式/大小不符合要求 | 检查格式（JPG/PNG）和大小（<10MB） |
| 草稿创建失败 48001 | 公众号未认证或 API 权限不足 | 改为手动发布 |
| 草稿创建失败 45005 | 正文超过字数限制 | 缩减正文内容 |
| 审查超时 | Agent B 响应时间过长 | 设置 60 秒超时，超时后跳过审查，降级发布 |
| 修复循环超过 3 轮 | 内容本身质量不足 | 降级发布 + 人工审核 |

## 7.2 紧急停止

如需紧急停止自动发布流程，禁用或删除对应的定时任务即可。任务定义参考 [[业务/写作/通用/08-定时任务通用规范]]。

停止后，已生成的文章可在工作区内手动处理。
