# 发布与确认

## 5.1 发布流程

```bash
# 读取 state
cat output/state.json | jq '.media_id'

# 创建微信草稿
python3 {{WORKSPACE}}/tools/game-discount-agent/publish_draft.py

# 产出: media_id 写入 state.json，status → published
```

详细 API 调用见 [[业务/写作/公众号/创作规范/公众号API开发手册/API参考]]。

## 5.2 发布后确认

发布后检查：

| 检查项 | 方法 | 失败处理 |
|--------|------|----------|
| 草稿创建成功 | media_id 非空 | 重试 1 次，仍失败则人工介入 |
| 文章可预览 | 通过公众号后台查看 | 检查 HTML 格式 |
| 无审核驳回 | 等待 5 分钟后检查状态 | 如被驳回，分析原因并记录 |
