# 流程总览

## 双 Agent 流水线

```
┌─────────────────────────────────────────────────────────────┐
│                    Agent A：内容开发                          │
│                                                             │
│  数据抓取 → 内容生成 → HTML 渲染 → 自检（12 项） → 输出 state │
└──────────────────────────┬──────────────────────────────────┘
                           │ state JSON
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                  Agent B：质量审查（独立）                     │
│                                                             │
│  加载 state → 23 项检查 → 生成审查报告                        │
│                                                             │
│  结果分类：                                                  │
│    BLOCKING = 阻断发布，必须修复                              │
│    WARNING  = 记录警告，不阻断                                │
│    INFO     = 信息记录，供参考                                │
└──────────────────────────┬──────────────────────────────────┘
                           │
              ┌────────────┴────────────┐
              │  BLOCKING 数量 = 0？     │
              └────────────┬────────────┘
                    ┌──────┴──────┐
                   YES            NO
                    │              │
                    ▼              ▼
              ┌─────────┐   ┌──────────────┐
              │  发布    │   │  修复循环     │
              │  草稿    │   │  （最多 3 轮） │
              └─────────┘   └──────┬───────┘
                                   │
                          修复后重新提交审查
                                   │
                          3 轮后仍有 BLOCKING？
                             ┌─────┴─────┐
                            YES          NO
                             │            │
                             ▼            ▼
                       ┌──────────┐  ┌─────────┐
                       │ 降级发布  │  │  发布   │
                       │（原始内容）│  │  草稿   │
                       └──────────┘  └─────────┘
```

## 角色说明

> 本文档中的「Agent A / Agent B」是业务分工角色，与「多 Agent 知识库协作规范」是不同维度：
> - 本文档 = Agent 如何分工完成公众号发布（业务层面）
> - 知识库协作规范 = Agent 之间如何通过 git 协作（基础设施层面）
> - 两者共同约束：Agent A/B 执行发布流程时，也必须遵守知识库协作规范的 git 操作要求
